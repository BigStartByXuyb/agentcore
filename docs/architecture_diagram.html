2. Agent Loop 主循环流程（Generator 模式）

flowchart TD
    A["用户输入"] --> B["agent_loop():
注入 skill/agent reminder"]
    B --> C["run_agent_loop() Generator"]
    C --> D["调用 LLM API
stream: yield from _stream_call()
逐 token yield TextDelta"]
    D --> E{stop_reason?}
    E -->|end_turn| F["yield TokenUsage
return 最终文本"]
    E -->|tool_use| G["遍历 tool_use blocks"]
    G --> H["yield ToolStart"]
    H --> I["yield from run_tool_use()
普通 executor: 直接返回
generator executor: 冒泡子事件"]
    I --> J["yield ToolEnd
is_error + result_summary"]
    J --> K["收集 tool_result + new_messages"]
    K --> L{有 new_messages?}
    L -->|否| D
    L -->|是| M["插入 assistant 占位
注入 skill-content"]
    M --> N{有 context_modifier?}
    N -->|是| O["应用 modifier
重建 tool schemas"]
    N -->|否| D
    O --> D
    C --> P["consume_events(gen, default_handler)
迭代事件 → 打印终端 → 返回文本"]

    CHECK -->|"否 — 普通 executor

    DATA --> NM["new_messages

    DATA --> CM["context_modifier

7. 错误处理流程

flowchart TD
    API_CALL["调用 LLM API
query_model / create_stream_with_retry"]

    subgraph API_LAYER["api.py 重试层"]
        direction TB
        API_TRY["发送请求"] --> API_CHK{异常类型?}
        API_CHK -->|"retryable
429 / 529 / 5xx / 连接错误"| API_RETRY["指数退避重试
最多 3 次
yield RetryNotice"]
        API_RETRY --> API_EXHAUST{重试耗尽?}
        API_EXHAUST -->|否| API_TRY
        API_EXHAUST -->|是| API_RAISE["raise 异常"]
        API_CHK -->|"non-retryable
400 / 401 / 403 等"| API_RAISE
        API_CHK -->|成功| API_OK["返回 response"]
    end

    API_CALL --> API_LAYER

    subgraph LOOP_LAYER["agent_loop.py 错误处理层"]
        direction TB
        LOOP_CATCH["捕获异常"] --> THINK{"_is_thinking_400()?"}
        THINK -->|是| STRIP["strip thinking blocks
+ filter orphaned messages"]
        STRIP --> LOOP_RETRY["重试一次
（再走一遍 api.py 重试层）"]
        LOOP_RETRY --> LOOP_ERR{又失败?}
        LOOP_ERR -->|否| LOOP_OK["正常处理 response"]
        LOOP_ERR -->|是| SYNTH["create_assistant_error_message()
内部调 classify_api_error()
注入 synthetic assistant 消息"]
        THINK -->|否| SYNTH
        SYNTH --> ERR_EVT["yield ErrorEvent
return 错误文本"]
    end

    API_RAISE --> LOOP_LAYER
    API_OK --> NORMAL["正常处理 response"]

    TOOL_CALL["工具执行"] --> TOOL_ERR{executor 异常?}
    TOOL_ERR -->|否| MAP["map_result(data)"]
    TOOL_ERR -->|是| TERR["is_error=True
tool_use_error 包裹"]
    MAP --> MAP_ERR{map_result 异常?}
    MAP_ERR -->|否| OK["return (ToolResult, text, False)"]
    MAP_ERR -->|是| TERR
