User is designing a desktop AI-powered code editor (similar to Cursor).

Tech stack decided:
- Electron (desktop shell)
- React + TypeScript (UI)
- Monaco Editor (editor core)
- Vite (build tool)
- Zustand (state management)
- OpenAI SDK or Ollama (LLM layer)

Key requirement: code must follow industrial/production-grade standards.

The editor layout is: file tree (left sidebar) + Monaco editor (center) + Agent chat panel (right).
